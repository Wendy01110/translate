# AI Translate

本机划词翻译和截图翻译。选中外文按热键即可看到译文；圈选屏幕可以先识别文字再翻译；也可以在输入窗口里粘贴或键入后再译。

## 快捷安装

需要 macOS 13+ 和 Python 3.12+。在仓库根目录执行：

```bash
./scripts/install.sh
```

脚本会创建 `.venv`、安装依赖，并把 `AI Translate.app` 装到 `~/Applications`，然后打开它。本机只保留这一份 App。改完源码后先点菜单「退出」，再重新打开；启动器会加载仓库里的代码，一般不用重新打包。

## 第一次使用

1. 在「系统设置 → 隐私与安全性」里，把 **AI Translate** 勾进辅助功能（自动读取选区）和屏幕录制（圈选翻译）。
2. 选中文字，松开 Option，再按 `Option+E`。翻译默认使用 **Google（内置）**，不用填密钥。
3. 要改来源、密钥或热键，点「译」→「设置…」。也可以改成 Bing / DeepL 内置，或 OpenAI 兼容 / 官方 API。

OCR 默认先用本机识别；看不清时才会用你配置的 OCR 模型。没有 OCR 模型也可以先用本机识别。

## 日常使用

默认热键：划词 `Option+E`，截图 `Option+W`。可在设置里点热键按钮后按下新组合；必须带修饰键，两组不能相同。

| 你想做的事 | 怎么做 |
| --- | --- |
| 划词翻译 | 选中文字，松开 Option，再按 `Option+E` |
| 截图翻译 | 按 `Option+W`，圈选区域 |
| 从菜单触发 | 「译」→「划词翻译」或「截图翻译」 |
| 输入或粘贴后再译 | 「译」→「输入翻译…」，点「翻译」或 `Command+Return` |
| 改来源、模型、密钥或热键 | 「译」→「设置…」；「应用」立即生效并留在窗口，「保存」写入后关闭 |
| 退出 | 「译」→「退出」 |

浮窗上面是原文，下面是译文，可滚动。点一下浮窗后可用 `Command+C` 复制；未选中时复制当前栏全部文字。

## 权限

热键本身不需要辅助功能。没有辅助功能时，先 `Command+C` 再按 `Option+E`，会翻译剪贴板。圈选翻译需要屏幕录制。菜单里的「辅助功能：未开启」可打开系统设置。授权对象必须是 **AI Translate**，不是 Cursor 或 python。

## 配置

翻译和 OCR 分开配置，互不借用。设置保存在本机的一份 `.env` 里，不会打进 App。密钥用密文框填写；不要提交到 Git，也不要在终端里长期 `export TRANSLATE_*` / `OCR_*`，否则设置页看起来会没保存成功。

仓库里如果已经有 `.env`，App 会优先用它。进阶字段见 `.env.example`。

## 命令行

安装后也可以用命令行：

```bash
.venv/bin/ai-translate config-check
.venv/bin/ai-translate text "Hello"
.venv/bin/ai-translate ocr --image page.png
.venv/bin/ai-translate ocr-translate --screenshot
.venv/bin/ai-translate listen
```

`config-check` 只表示配置被读到，不表示翻译一定能通。`listen` 在终端里注册同一组热键，用 `Ctrl+C` 退出。

## 常见问题

- **设置打不开或改完没变化**：点「应用」或「保存」后才会生效。仍不对就先「退出」再打开 App。
- **划词没读到选区**：给 AI Translate 打开辅助功能；先松开 Option；或先复制再按热键。
- **OCR 没反应**：打开屏幕录制；取消圈选不会识别。
- **热键变成了奇怪字符**：在设置里点按钮录制，不要手填 Option 产生的符号。
- **浮窗里 Command+C 没反应**：先点一下原文或译文，再复制。未选中时会复制当前栏全部文字。
- **网页翻译失败**：内置源可能被限流。可换官方密钥源，或稍后再试。

划词会短暂改写剪贴板并在结束后恢复，翻译过程中不要同时复制其它内容。

## 目前没有的功能

历史记录和视频字幕还没有。本工具也不做全书对照翻译、同声传译、浏览器扩展或多人在线服务。

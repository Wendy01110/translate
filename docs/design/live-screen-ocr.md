# 屏幕实时 OCR

本文适用于锁定屏幕区域后的有界 OCR 翻译循环，面向实现者。某次视频或窗口上的识别结果不属于本文。

## 目标与非目标

- 目标：用户圈定一块区域后，程序按固定间隔截取该区域，对变化画面识别并翻译，把译文叠在区域外侧；成功结果去重，暂态翻译失败允许有界恢复。
- 目标：复用现有 OCR 端口和翻译端口，不另写一套译文语义。
- 非目标：系统音频转写、整屏逐帧、平台字幕接口、片源离线抽流。

## 核心约束

- 开始必须先圈选；取消圈选不截屏、不调用上游。
- 圈选必须由平台 UI 主线程异步回调结果，不得在主线程手写阻塞轮询；圈选中再次触发实时热键会取消圈选，单次 OCR 触发则忽略，不得重入第二个圈选器。
- 发起圈选就在监听器状态锁内预留会话代次；排队启动、同步结果和异步完成回调都绑定该代次。停止立即使旧代次失效，迟到的旧矩形、取消结果或初始化异常均不得启动或清掉新会话；同一回调重复投递只接受第一次有效结果。
- 每轮目标起点间隔固定为 0.8 秒；截屏、OCR 和翻译耗时计入间隔，某轮超过目标间隔时结束后再继续，不得并行打两条实时流。
- 截屏范围必须是用户圈定的矩形，不得改成整屏。固定区域在抓图前检查有限坐标和区域坐标面积上限，抓图后检查非空及 20 MiB 字节上限；坐标单位与错误边界见 [OCR 分流](./ocr-routing.md)。
- macOS 圈选在每个 `NSScreen` 上分别创建一个共享会话的透明面板，兼容“显示器具有独立空间”时从任意屏幕开始拖拽；圈选和字幕条使用 AppKit 左下原点全局坐标，固定截屏前按主显示器高度转换为 Quartz 左上原点坐标。Windows 也为每块物理显示器创建一个共享会话的 Qt Quick 覆盖层；QML 逻辑像素通过当前窗口 `devicePixelRatio` 转成虚拟桌面左上原点的全局物理像素，并保留负坐标副屏。
- 图片指纹相同则不调用 OCR；识别文本与上一拍相同且没有到期的翻译补试则不调用翻译。画面变化但文字相同必须保留原补试次数和截止时间，不能因帧变化不断重置次数。
- 仅对 OCR 成功后的翻译暂态错误 `timeout`、`http_error`、`http_408`、`http_429`、`http_500`、`http_502`、`http_503`、`http_504` 补试，最多两次，分别在前一次失败完成后至少 2 秒和 5 秒，由下一轮循环触发。同一画面的补试复用已识别文字与来源，不重新执行 OCR；不额外创建线程或睡眠。成功或识别文字变化后重置补试状态；耗尽后同一句文字继续跳过，用户可以停止并重开实时翻译。鉴权、配置、截断、空 OCR 和其它 OCR 失败不新增自动补试。
- 每个变化帧仍只调用同一个分流 `OcrEngine`：自动模式按本地普通、本地高级、API 普通、API 高级顺序串行升级，任一层成功后不得调用后续层，也不得并行竞速。
- 识别为空时字幕条清空，不得继续显示上一句译文。翻译失败时显示错误或空白，不得用上一句成功译文冒充当前句。
- 字幕条必须放在圈选区域外侧，避免把译文截进下一帧。macOS 按 `NSScreen.visibleFrame` 放置，先尝试下方、上方，再在两侧空间足够时尝试右侧、左侧；竖向空间少于内容所需高度但能容纳最小窗口时缩小高度。没有任何可用外侧空间时保留区域外的放置，窗口可能在屏幕之外，用户应缩小圈选区域，不得为留在屏内而覆盖捕获区。Windows 字幕条高度按内容与窗口 DPI 有界调整，不能用固定物理像素上限导致 150%/200% 缩放下裁掉状态或停止入口。
- macOS 字幕条复用普通工作区的只读、可选中、可换行滚动文本组件，译文在上、灰色原文在下；按实际文本排版、滚动区边框和窗口标题栏尺寸计算高度，窗口总高为 112～240 AppKit 点，原文显示区最多 40 点，剩余空间优先留给译文。原文为空时隐藏其区域，长文保留完整内容并可分别滚动阅读。新结果与窗口缩放均重算布局，保留用户调整的宽度并重新放在圈选区域外侧；更新不抢焦点，关闭仍触发停止回调。
- 停止后不再开始下一步截屏、OCR 或翻译；已在途的调用即使返回也必须丢弃，不能覆盖新一轮状态或重新弹出字幕条。关闭字幕条视为停止。
- 圈选到运行的状态提交和 worker 启动前检查使用现有状态锁；字幕条状态显示期间若已停止，不再启动 worker。旧 worker 退出时只能清理自己的当前代次，不能回写新会话的运行标志。
- 应用或保存设置会停止正在圈选及已经运行的实时会话，并取消当前 picker；旧回调继续按代次丢弃，用户按新设置重新圈选开始。只切换工作区目标语言栏继续遵循下一条的语言切换规则。
- 切换目标语言清空当前去重与补试状态，并让旧的不可变状态快照失效；在途 OCR/翻译结果不能回写或显示，即使切换后又切回原语言也一样。快照与语言读取、语言切换、结果提交使用短临界区，网络调用在锁外；实时循环保持运行，下一轮按新语言重新处理当前画面。
- 字幕条的显示和隐藏都必须回到平台 UI 主线程。
- `LiveResultPresenter` 在 UI 实际显示前重新调用 listener 提供的有效性谓词，同时检查会话代次和不可变语言/去重快照；只在工作线程入队前检查不足以阻止旧结果。显示期间若布局触发事件处理，再次检查后才前置窗口。平台显示代次在停止/隐藏和新区域开始时更新，旧状态、旧结果及旧隐藏请求均不能影响新会话；停止后的清空区域不能取消本次隐藏动作。
- Paddle 首次加载提醒复用当前字幕条，显示「本地 OCR 首次加载中，请稍候…」，不打开普通翻译工作区；完整模型与下载说明由普通 OCR 工作区和用户文档承载。
- 实时路径不得读取翻译配置去顶替 OCR，也不得把图像直接交给翻译端口。

## 主流程

```text
热键 alt+q 或菜单「实时翻译」
  -> 若已在运行则停止
  -> 拖拽圈选区域（Esc 或空选取消）
  -> 字幕条显示识别中
  -> 循环：
       截取矩形
       -> 指纹未变且无到期补试：跳过
       -> 变化帧执行 OCR；相同帧的到期补试复用 OCR 结果
       -> 文本未变且无到期补试：跳过翻译
       -> 翻译
       -> 任务仍有效：更新字幕条与有界补试状态
  -> 再次热键 / 菜单「停止实时翻译」 / 关闭字幕条：结束循环
```

## 变更与验证要求

- 修改间隔、跳过规则或失败是否沿用旧译文时，同步本文、`advance_live` 测试和用户 README。
- 修改字幕布局时验证短文、长中文/英文、多行、错误与清空状态、宽度改变、高度上限和区域外放置；原生文本滚动、复制与关闭回调使用合成输入，不以纯矩形测试替代原生显示证据。
- 圈选、截屏和循环必须可注入，默认测试不得截真实屏幕、初始化 PaddleOCR 模型、调用 Vision、OCR.space、API 高级 OCR 或翻译上游。
- 不得在测试或文档中写入真实截屏、识别全文或密钥。

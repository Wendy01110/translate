# 有界本地翻译历史

> 状态：已完成
>
> 创建日期：2026-10-06（Asia/Shanghai）

## 目标与范围

Requester 对上一轮五项检查要求“都做好吧”，本轮实施原[后续能力计划](../pending/2026-08-19-ttime-inspired-follow-on.md)中的有界历史，其它新能力仍待进行。按推荐默认关闭，由用户在历史窗口开启；只保存成功的输入、划词和单次 OCR 翻译，不保存实时字幕、失败或部分结果。

## 明确规则

- 本地 JSON 保存开启状态及最多 50 条记录，原文与译文每栏最多 8000 字符，文件最多 1 MiB；超出单栏预算的结果不记入历史，仍正常展示。达到条数或文件预算时移除最旧记录，连续相同内容和语言不重复保存。
- 记录仅含原文、译文、文本/截图类别、请求时的源/目标语言和 UTC 时间；输入和划词共用既有文本类别，不推断外部应用。不含截图、密钥、配置、模型上游原始响应或日志全文。
- macOS 存在本机 Application Support 的 AI Translate 目录，Windows 存在 AppData 的 AI Translate 目录；开关与记录同存，不添加环境变量或改变双模型配置。
- 复用平台菜单/托盘入口与原翻译工作区，提供查看、预览、复用和清空。复用只填入工作区并同步目标语言，不自动请求、不重复保存；再次点击翻译才发起请求。
- 关闭保存后保留已有记录供查看，可显式清空；文件损坏或写入失败必须提示且不影响翻译。损坏文件在用户明确清空前不覆盖。

## 验收与副作用

默认测试使用临时目录、Fake 端口及 Fake UI；验证默认关闭、只记录成功单次结果、请求语言快照、去重、条数和 UTF-8 文件预算、重新加载、损坏和写入失败、开启/关闭/清空及复用无请求。原生 UI 与正式 App 使用合成内容验收，正式历史文件只读，测试记录写入隔离路径。

用户开启保存或清空时会写本机历史文件，清空只作用于该文件的记录；开发验证不接触现有用户历史，不改真实 `.env`。不新增数据库、依赖、后台服务、自动剪贴板监听或云同步。

## 目标与范围

修复已离线复现的三个问题：实时 OCR 在途请求覆盖目标语言切换后的状态、一次翻译暂态失败导致相同文字永久跳过，以及 OpenAI 兼容翻译把长度截断回复标记为成功。

影响范围为实时翻译用例、桌面监听器、兼容响应解析、共用错误文案、对应测试和直接相关文档。沿用现有分层、端口、三种结果状态和独立双模型配置，不新增依赖或配置项。

## 实施与验收

1. 为实时任务保留一致的语言与去重状态快照；切换目标语言后，在途旧任务不能显示结果或回写记忆，当前循环下一轮继续使用新语言。
2. 实时 OCR 成功后的翻译仅对 timeout、http_error、HTTP 408/429/500/502/503/504 补试，最多两次，分别在上次失败后至少 2 秒、5 秒；相同画面复用 OCR 结果，画面变化但文字相同仍共享次数和等待时间。成功、文字变化或显式重开/切语言后重置相应状态；鉴权、配置、截断和空 OCR 不新增自动重试。
3. 翻译和 OCR 共用兼容响应内容与完成原因解析；翻译遇到 finish_reason=length 返回明确失败，不展示残缺译文，OCR 后翻译仍保留已识别原文并返回 partial。
4. 使用 Fake 时钟、端口和 HTTP mock 验证等待时间、次数上限、文字变化、停止与语言切换、截断和正常结果；执行相关定向测试、完整离线套件及 git diff --check。
5. 同步 README、稳定设计与状态索引，写完成日志并移动本计划原文件。

## 授权、外部副作用与停止边界

用户授权本项目本地优化及最小必要验证。本轮不调用真实模型或 OCR、不读取选区/剪贴板、不截屏、不写真实配置、不安装依赖、不重启 App、不提交或发布。新重试行为只在用户后续运行实时翻译时生效，保持串行和次数上限。保留原有浮窗失焦修改及其文档 WIP。

设置应用后的模型复用、其它输入边界和原四层 OCR 计划的 macOS 点击级验收不纳入本轮。若实现需要扩大到真实外部调用、桌面操作或无界重试，停止该扩展并说明。

# 屏幕实时 OCR 翻译计划

> 状态：进行中
>
> 创建日期：2026-08-20（Asia/Shanghai）

## 目标

让用户圈定一块屏幕区域后，按有界间隔持续识别其中的文字并翻译，把译文叠在该区域外侧。用于视频硬字幕、课件和会变化的界面文字。本轮只做像素 OCR 循环，不做系统音频转写。

## 当前依据

- 现有 OCR 翻译是单次路径：`screencapture -i` 圈选一张图，再走 `OcrTranslateService` 和划词共用的翻译端口；浮窗是原文/译文卡片。
- `RegionScreenshot` 不返回坐标，无法对同一区域再次截取。
- 本机 Vision 适合短间隔识别；Unlimited-OCR 单次可达数秒，实时循环必须允许哈希跳过和文本去重，且不得为“更实时”去掉间隔。
- 产品范围把「字幕同传」列为非目标，实施前必须改成：允许有界区域实时 OCR，继续排除系统音频同传、整屏逐帧和平台字幕接口。
- 待进行计划 [视频字幕实时识别](../pending/2026-08-19-live-video-subtitles.md) 的路径 A 即本能力；路径 B（系统音频转写）仍不在本轮。

## 范围与非目标

- 范围：第三热键和菜单「实时翻译」；拖拽圈定区域并记住坐标；固定矩形截屏；画面哈希未变则跳过 OCR；识别文本未变则跳过翻译；字幕条浮层展示译文（可附原文）；同一热键/菜单/关闭浮层停止后不再截屏、不再请求。
- 范围：复用现有 `OcrEngine` 与 `Translator`，不得为实时路径另写译文语义；默认目标起点间隔 0.8 秒，硬编码常量，本轮不新增间隔环境变量。
- 范围：离线测试用假区域、假帧和假端口覆盖跳过、去重、失败清空和开停。
- 非目标：系统音频 / ASR、下载或破解视频站字幕、片源离线抽流、整屏逐帧、多语言双字幕编辑器、历史、Electron。
- 非目标：把图像直接交给翻译模型，或用 OCR 配置顶替翻译。

## 执行步骤

1. 把有界区域实时 OCR 写入产品范围、架构和桌面热键设计，并新增 [屏幕实时 OCR](../../design/live-screen-ocr.md)。
2. 在 `core` 增加 `ScreenRect`；在 `OcrTranslateService` 增加 `advance_live`（哈希跳过、空识别清空、同句去重、失败不沿用上一句译文）。
3. 在 `infrastructure` 增加固定矩形截屏和图片指纹；圈选改为 AppKit 拖拽，不再用 `screencapture -i` 冒充锁定区域。
4. 字幕条浮层放在圈选区域外侧，避免把译文截进下一帧；更新时不得抢焦点。
5. `listen` / 菜单栏接入开始、停止和串行 tick；设置页增加 `HOTKEY_LIVE_OCR`（默认 `alt+q`），三组热键不得相同。
6. 同步 `.env.example`、`config-check`、根 README 和契约测试；跑相关离线套件。

## 验收条件

- 用户能明确开始和停止；停止后不再截屏、不再调用 OCR 或翻译。
- 画面未变化时不发起 OCR；识别文本未变时不发起翻译；翻译失败时字幕条显示错误或空白，不拿上一句成功译文冒充当前句。
- 实时路径与单次圈选 OCR 共用同一 OCR 端口和同一翻译端口。
- 取消圈选不调用上游。实时循环进行中，划词热键仍可用；单次 OCR 热键可忽略或等当前 tick 结束，不得再开第二条实时流。
- 离线测试用假帧和假端口，CI 不截真实屏幕、不打真实模型。
- `config-check` 回读实时热键；密钥、截屏原图和识别全文不进日志。

## 授权与停止边界

- 允许：实现圈选、固定区域截屏、哈希/去重、字幕条、热键/菜单、离线测试和文档同步。
- 需要额外授权：本机真实屏幕录制循环、真实 Vision / Unlimited-OCR / 翻译连续调用、付费压测、提交和推送。
- 出现以下情况停止：去掉最短间隔或去重、整屏逐帧、用翻译模型看图、用 OCR 模型听声音、同时做 ASR。

## 当前进度

- 已落地 `advance_live`、固定矩形截屏、圈选、字幕条、热键/菜单开停、`HOTKEY_LIVE_OCR` 和离线测试。
- 已补齐 AppKit 到 Quartz 的圈选坐标转换；圈选期间不会重入第二个圈选器；停止或快速重启时会丢弃旧 tick，OCR 返回前已停止则不再开始翻译，旧结果不会重新弹出字幕条；手工配置的三组重复热键会在加载时被拒绝。
- 真机首次按 `Option+Q` 时卡住；进程采样确认主线程停在圈选器手写的 `NSRunLoop.runMode` 轮询。圈选已改为主线程异步回调，圈选中再次按 `Option+Q` 可取消，不再占住菜单栏事件循环。
- 真机复验反馈翻译跟不上变化文字；检查确认旧循环在每轮完整处理后额外等待 1.5 秒。现已改为约 0.8 秒的目标起点间隔，处理耗时计入间隔，继续保持单线程串行和去重。
- 实时监听定向测试 26 项、完整离线套件 192 项已通过。未完成本机真实模型连续调用的时延验收。
- 待重启 App 复验：`Option+Q` 能拖拽圈选且菜单栏不冻结，变化文字的检测节奏有改善，字幕条更新后再次按键或关闭字幕条能停止。

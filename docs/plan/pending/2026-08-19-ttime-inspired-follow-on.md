# TTime 对照后的后续能力计划

> 状态：待进行
>
> 创建日期：2026-08-19（Asia/Shanghai）

## 目标

对照 [TTime](https://github.com/InkTimeRecord/TTime) 的桌面翻译体验，列出本项目值得做、且与双模型架构兼容的后续能力。本计划只做取舍和顺序，不在本轮实施。

## 当前依据

- TTime 是 Electron 桌面翻译器，主能力是划词、截图 OCR、输入框翻译、悬浮球、划词工具栏、多翻译源、历史、剪贴板监听和语音播放。
- 本项目定位是本机 AI 翻译：翻译模型和 OCR 模型分开配置。热键划词、热键 OCR、菜单栏 App 和输入能力已落地；macOS 输入入口、划词与单次 OCR 现共用一个翻译工作区。
- 本项目不复制 TTime 的多翻译源市场、离线包或跨平台安装包。DeepL / Microsoft / Google 官方 API 见 [官方翻译源接入](../completed/2026-08-19-official-translate-sources.md)。

## 建议纳入（按顺序）

1. 输入框翻译：已完成，见 [默认内置翻译源与输入框翻译](../completed/2026-08-20-default-provider-and-input-box.md)。
2. 菜单栏常驻：已完成，见 [macOS 菜单栏 App](../completed/2026-08-19-macos-menu-bar-app.md)。
3. 复制译文：macOS 普通结果浮窗已完成标题区复制按钮，只复制当前译文；Windows 复制入口已纳入 [Windows 桌面 UI 优化](./2026-09-01-windows-ui-optimization.md)，仍需在统一工作区实施和真机验收后才能标记完成。
4. 有界历史：本地保存有限条记录并限制文本长度，不含图片和密钥。
5. 划词工具栏：鼠标松开后在选区旁出现「译」按钮，减少记热键。依赖更稳的选区检测，且必须可关闭。
6. 剪贴板监听：可选开启，复制后自动翻译。默认关闭，避免把剪贴板上传变成默认行为。
7. 语音播放：翻译结果 TTS，需单独配置语音模型或系统 `say`，不得占用 OCR/翻译配置。

## 明确不做或后置

- 多源同时展示、插件市场、有道/百度/腾讯、内置离线词典：本轮不做。Google/Bing/DeepL 网页内置源见 [内置网页翻译源](../completed/2026-08-19-web-translate-sources.md)。
- Linux 安装包和自动更新继续后置；Windows 桌面入口已拆到 [Windows 桌面版 MVP](../in-progress/2026-08-20-windows-mvp.md)，首版不做自动更新。
- 主题商店、多语言 UI、账号同步：不是当前痛点。
- 悬浮球拖拽：可被菜单栏替代，不单独作为下一阶段。

## 验收条件（将来实施时）

- 每一项都有独立开关或入口，失败不影响热键划词/OCR。
- 新增能力不得让 OCR 走翻译配置，也不得默认上传剪贴板。
- 历史和日志仍禁止写入密钥、截屏原图和未脱敏上游响应。

## 授权与停止边界

- 允许：本清单其余项仍留在 `pending/`，不在本轮实施。
- 需要额外授权：开始实施历史/工具栏/剪贴板监听、真实 TTS 调用。
- 出现“为了像 TTime 而同时做完以上全部”时停止，必须一项一项做。

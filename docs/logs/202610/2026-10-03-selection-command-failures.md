## 问题与实际改动

- macOS 的 `pbpaste`、`pbcopy` 和 `osascript` 启动、超时或文本编解码异常原先会越过 `SelectionReadError` 消费路径，监听器无法提交失败结果；现已在三个命令适配函数内转换为对应的既有读、写、复制错误码。
- 使用 `raise ... from None` 抑制原始异常链的普通 traceback 展示，错误结果只保留稳定码；没有添加普通日志或输出剪贴板内容。
- 保持 2/2/5 秒命令超时、Quartz 优先复制、辅助功能判断、`finally` 恢复和 Windows 手动复制回退规则。复制或读取失败后可恢复时仍恢复原剪贴板；恢复写入失败明确返回写入失败，不继续翻译。
- 新增合成子进程与剪贴板回归，覆盖启动/超时/编码/解码异常、成功/非零退出、Quartz 成功跳过 System Events、各取词阶段失败展示，以及故障解除后再次触发和忙碌锁释放。
- 同步 README 常见问题、macOS 热键设计、架构失败边界、文档入口和计划索引；未修改配置、CLI、端口、结果字段、依赖或其它平台实现。

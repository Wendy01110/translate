# macOS 翻译窗口失焦保留

> 日期：2026-09-08（Asia/Shanghai）

## 改动

- 用户反馈普通翻译窗口点击其它地方后应留在后台。移除 `window_did_resign_key()` 中主动隐藏窗口的 `orderOut`，以及仅为该调用设置的重入标记。
- 未置顶窗口继续使用普通层级，失焦后保留可见性并允许其它窗口覆盖；保留下一次查询跟随鼠标所在屏幕重新前置的标记。置顶和实时字幕条行为不变。
- 同步根 README、文档入口、桌面热键设计和架构设计。本次为一次性局部修复，无新增 Plan 或 Issue；四层 OCR 计划仍保持原状态。
